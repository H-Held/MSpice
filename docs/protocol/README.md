# Co-simulation protocol

Specification of the protocol between the MSpice engine and firmware
endpoints (emulators, hardware adapters). Not written yet; see task SIL-00 in
[TASKS.md](../TASKS.md). The draft message set is in the plan of the
[mspice-emu](https://github.com/H-Held/mspice-emu) repository.

This specification is licensed like the rest of MSpice's documentation, and
anyone may implement it in software under any licence.
