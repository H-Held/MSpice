# E0001: TOML syntax error

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 1.

The file is not valid TOML, so nothing else in it can be checked. The message
repeats the parser's description and points at the place where parsing
stopped. Common causes: a missing closing quote, a missing `=`, a key that
appears twice, a table header written twice, or keys added to `[model]`
after an `[[model.elements]]` entry (TOML assigns them to the element).

## Wrong

```toml
name = "Resistor
version = "0.1.0"
```

## Correct

```toml
name = "Resistor"
version = "0.1.0"
```

To see this text in a terminal: `mspice-libcheck explain E0001`.
