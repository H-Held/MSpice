# E0002: file cannot be read

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 2.

A file that the validator needs cannot be read: a path given on the command
line, a part file listed explicitly (without wildcards) in the `parts` list
of a library manifest, or a data file that exists but is not readable.
Paths in `parts` are relative to the directory of `library.toml`.

## Wrong

```toml
[library]
parts = ["parts/generic_resistor.tml"]
```

## Correct

```toml
[library]
parts = ["parts/generic_resistor.toml"]
```

To see this text in a terminal: `mspice-libcheck explain E0002`.
