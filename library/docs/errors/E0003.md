# E0003: missing or unsupported format_version

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 1, 18.

Every part file and manifest starts with `format_version = "0.1"`. The
validator only reads the format version it was built for; a missing or
different version is reported so that a file written for another version is
not silently misread.

## Wrong

```toml
# SPDX-License-Identifier: CC-BY-4.0
[part]
id = "generic_resistor"
```

## Correct

```toml
# SPDX-License-Identifier: CC-BY-4.0
format_version = "0.1"

[part]
id = "generic_resistor"
```

To see this text in a terminal: `mspice-libcheck explain E0003`.
