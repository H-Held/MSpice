# E0004: unknown or misplaced key

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 1.

The table contains a key that the format does not define there. Unknown keys
are never ignored, because a misspelt key would otherwise silently fall back
to a default. The hint names the closest known key. The same code is used for
keys that exist in the format but do not belong to this place, for example
`branches` in a model of kind `primitive`, `expr` in a load branch with mode
`fixed`, or `frequency` in a white-noise source.

## Wrong

```toml
[part]
id = "generic_resistor"
nmae = "Resistor"
```

## Correct

```toml
[part]
id = "generic_resistor"
name = "Resistor"
```

To see this text in a terminal: `mspice-libcheck explain E0004`.
