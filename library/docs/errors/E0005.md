# E0005: missing required key

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 4.2.

A key that the format requires is missing. Some keys are required only in a
certain context: `unit` for real and integer parameters, `choices` for enum
parameters, `value` for a load branch with mode `fixed`, `stop` for a
transient test, the type-specific keys of a noise source. The hint shows the
expected value type.

## Wrong

```toml
[part]
id = "generic_resistor"
name = "Resistor"
version = "0.1.0"
# author is missing
```

## Correct

```toml
[part]
id = "generic_resistor"
name = "Resistor"
version = "0.1.0"
author = "The MSpice Authors"
```

To see this text in a terminal: `mspice-libcheck explain E0005`.
