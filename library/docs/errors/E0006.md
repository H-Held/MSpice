# E0006: wrong value type

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 5.1, 7.

The value has the wrong TOML type, for example a string where a boolean is
expected, a single table where an array of tables (`[[...]]`) is expected,
or a float where an integer is expected. Limits (`abs_max_voltage`, `min`,
`max`, `default`) must be fixed values; an expression in braces is not allowed
there.

## Wrong

```toml
[[parameters]]
name = "resistance"
type = "real"
unit = "Ohm"
default = "1 kOhm"
adjustable = "yes"
```

## Correct

```toml
[[parameters]]
name = "resistance"
type = "real"
unit = "Ohm"
default = "1 kOhm"
adjustable = true
```

To see this text in a terminal: `mspice-libcheck explain E0006`.
