# E0007: value is not one of the allowed words

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 4.2, 6, 9.

The key accepts only a fixed set of words (for example `role`, `quality`,
`kind`, `mode`, `type` of an element), or the value of an enum parameter must
be one of its `choices`. The message lists all allowed values; the hint names
the closest one.

## Wrong

```toml
[[pins]]
name = "vdd"
role = "pwr"
```

## Correct

```toml
[[pins]]
name = "vdd"
role = "power"
```

To see this text in a terminal: `mspice-libcheck explain E0007`.
