# E0010: invalid part id

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 4.2.

Part ids follow `^generic_[a-z0-9_]+$`. Ids describe the function, never a
vendor part number, so that the library does not use trademarks as names and
one model can serve several compatible products. Real part numbers go into
`compatible`.

## Wrong

```toml
[part]
id = "WS2812B"
```

## Correct

```toml
[part]
id = "generic_rgb_led_addressable"
compatible = ["WS2812B"]
```

To see this text in a terminal: `mspice-libcheck explain E0010`.
