# E0011: duplicate part id

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 2.

Two part files in the same library (or in the same set of checked files)
use the same `id`. Ids must be unique, because instances and other parts
refer to parts by id. If two libraries define the same id, that is a merge
question (E0123), not this error.

## Wrong

```toml
# parts/generic_led.toml
id = "generic_led"
# parts/generic_led_red.toml
id = "generic_led"
```

## Correct

```toml
# parts/generic_led.toml
id = "generic_led"
# parts/generic_led_red.toml
id = "generic_led_red"
```

To see this text in a terminal: `mspice-libcheck explain E0011`.
