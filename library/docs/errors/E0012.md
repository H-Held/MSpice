# E0012: invalid name

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 4.2, 6, 7, 15.2.

A name does not follow its naming rule. Parameters, features, signals,
variables, inputs, states, curves and tests use `^[a-z][a-z0-9_]*$`; pins and
nodes `^[A-Za-z0-9_]+$`; elements and stimuli start with a letter. Names of
built-in functions and variables (`time`, `temp`, `pi`, `v`, `i`, `sqrt`, ...)
are reserved. Categories are lower-case words separated by `/`; library names
may also contain `-`.

## Wrong

```toml
[[parameters]]
name = "Resistance"
```

## Correct

```toml
[[parameters]]
name = "resistance"
```

To see this text in a terminal: `mspice-libcheck explain E0012`.
