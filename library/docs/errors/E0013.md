# E0013: duplicate name

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 7, 9.

A name is defined twice in the same scope. Parameters, signals, state
machine variables, inputs and curves share one namespace because they can all
appear in expressions. Elements, outputs and branches share another, because
`I(name)` and state `values` refer to them. Internal nodes must not repeat a
pin name.

## Wrong

```toml
[[parameters]]
name = "gain"
# ...
[[model.signals]]
name = "gain"
```

## Correct

```toml
[[parameters]]
name = "gain"
# ...
[[model.signals]]
name = "gain_filtered"
```
