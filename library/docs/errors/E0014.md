# E0014: invalid version or version requirement

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 2, 4.2.

A version must be a semantic version `MAJOR.MINOR.PATCH`, optionally with a
pre-release suffix (`1.0.0-rc.1`). Version requirements of dependencies are a
comma-separated list of comparators: `=`, `>`, `>=`, `<`, `<=`, `^`, `~`.

## Wrong

```toml
[part]
version = "1.0"
```

## Correct

```toml
[part]
version = "1.0.0"
```

To see this text in a terminal: `mspice-libcheck explain E0014`.
