# E0020: incomplete source

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 4.3.

Every part says where its values come from. `[part.source]` needs `kind` and
`title`; `vendor` is needed for datasheets, application notes and SPICE
models; `date` for measurements; `model_license` for SPICE models. Without
this, nobody can review or update the values.

## Wrong

```toml
[part.source]
kind = "datasheet"
vendor = "Example Corp"
```

## Correct

```toml
[part.source]
kind = "datasheet"
title = "EX123 Low-dropout regulator datasheet"
vendor = "Example Corp"
```

To see this text in a terminal: `mspice-libcheck explain E0020`.
