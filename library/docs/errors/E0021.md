# E0021: licence not accepted

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 4.2, 4.3.

Part data in this library is published under CC BY 4.0 (or CC0 1.0), so that
anyone, including companies, may use and redistribute it. Other licences are
not accepted in `[part] license` or in a library manifest. For parts derived
from a SPICE model, `source.model_license` must be an open licence; models
under proprietary vendor terms must not be converted at all.

## Wrong

```toml
[part]
license = "GPL-3.0-only"
```

## Correct

```toml
[part]
license = "CC-BY-4.0"
```

To see this text in a terminal: `mspice-libcheck explain E0021`.
