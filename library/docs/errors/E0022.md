# E0022: quality level requirements not met

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 4.4.

The quality level promises more than the file shows. `datasheet` needs a
datasheet (or application note or standard) with vendor, revision and
section, and at least one reference test; `measured` needs a measurement
source with date and a test. `vendor-verified` needs signatures, which do not
exist before roadmap stage 5. Use `draft` until the evidence is complete.

## Wrong

```toml
[part]
quality = "datasheet"

[part.source]
kind = "estimate"
title = "Typical values"
```

## Correct

```toml
[part]
quality = "draft"

[part.source]
kind = "estimate"
title = "Typical values"
```
