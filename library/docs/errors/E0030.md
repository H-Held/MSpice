# E0030: unknown unit

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 5.3.

The unit is not in the unit list of the specification. Units are written
exactly as listed (case matters: `Ohm`, not `ohm`; `Hz`, not `hz`). Use `"1"`
for dimensionless values. The same applies to the unit line of CSV files.

## Wrong

```toml
[[parameters]]
name = "resistance"
type = "real"
unit = "ohm"
```

## Correct

```toml
[[parameters]]
name = "resistance"
type = "real"
unit = "Ohm"
```

To see this text in a terminal: `mspice-libcheck explain E0030`.
