# E0031: unit mismatch

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 5.2, 13.1.

A quantity string carries a unit that differs from the unit of the field, or
a curve declares a unit that differs from the unit line of its CSV file.
Units are not converted; write the value in the unit of the field. A frequent
trap: `"5 m"` means five metres; milliohm is `"5 mOhm"`.

## Wrong

```toml
[[parameters]]
name = "resistance"
unit = "Ohm"
default = "1 kV"
```

## Correct

```toml
[[parameters]]
name = "resistance"
unit = "Ohm"
default = "1 kOhm"
```
