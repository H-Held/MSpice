# E0032: malformed quantity

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 5.2.

The string is neither a number with optional prefix and unit nor an
expression in braces. Quantities look like `"4.7 kOhm"`, `"100mA"`,
`"10k"` or `"2e-3 s"`. Shorthands such as `"4k7"` are not accepted.

## Wrong

```toml
default = "4k7"
```

## Correct

```toml
default = "4.7 kOhm"
```

To see this text in a terminal: `mspice-libcheck explain E0032`.
