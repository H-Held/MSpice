# E0033: value out of range

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 5.3, 7.

A value lies outside its allowed range: a parameter default outside
`min`/`max`, a negative current limit, a non-positive time constant, test
`stop` or sweep step, a negative tolerance or timeout.

## Wrong

```toml
[[parameters]]
name = "resistance"
default = "1 kOhm"
max = "100 Ohm"
```

## Correct

```toml
[[parameters]]
name = "resistance"
default = "1 kOhm"
max = "1 MOhm"
```

To see this text in a terminal: `mspice-libcheck explain E0033`.
