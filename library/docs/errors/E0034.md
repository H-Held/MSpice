# E0034: minimum greater than maximum

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 6, 7, 11.

A lower limit is greater than the upper limit: `min` above `max` of a
parameter, `abs_min_voltage` above `abs_max_voltage` of a pin, or the `low`
threshold of a state machine input above its `high` threshold.

## Wrong

```toml
min = "10 kOhm"
max = "100 Ohm"
```

## Correct

```toml
min = "100 Ohm"
max = "10 kOhm"
```

To see this text in a terminal: `mspice-libcheck explain E0034`.
