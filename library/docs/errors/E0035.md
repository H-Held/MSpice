# E0035: invalid tolerance

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 7.

The tolerance of a parameter is invalid: a relative tolerance outside [0, 1)
(write 0.05 for 5 %), a negative absolute tolerance, `sigma` without
`distribution = "normal"` or not positive, or a tolerance on a parameter that
is not real or integer.

## Wrong

```toml
tolerance = { relative = 5 }
```

## Correct

```toml
tolerance = { relative = 0.05 }
```

To see this text in a terminal: `mspice-libcheck explain E0035`.
