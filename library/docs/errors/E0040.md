# E0040: unknown pin or node

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 9.1.

A node, pin or element name is not defined. Inside a model, nodes are pin
names, `internal_nodes` and `0` (global ground). `I()` takes a pin or element
name. In tests, nodes are pins, nodes of test elements and `0`. Element
instances of other parts must use that part's pin names in the table form of
`nodes`.

## Wrong

```toml
[model]
kind = "primitive"
element = "R"
nodes = ["p", "m"]
```

## Correct

```toml
[model]
kind = "primitive"
element = "R"
nodes = ["p", "n"]
```

To see this text in a terminal: `mspice-libcheck explain E0040`.
