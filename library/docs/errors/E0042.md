# E0042: wrong number of nodes or unconnected pin

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 9.2, 9.3.

An element is connected to the wrong number of nodes, or an instance of
another part leaves one of its pins unconnected. The hint lists the node
order. `when_disabled = "short"` is only possible for two-terminal elements.

## Wrong

```toml
[model]
kind = "primitive"
element = "R"
nodes = ["p", "n", "p"]
```

## Correct

```toml
[model]
kind = "primitive"
element = "R"
nodes = ["p", "n"]
```

To see this text in a terminal: `mspice-libcheck explain E0042`.
