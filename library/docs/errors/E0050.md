# E0050: parameter is not adjustable

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 7.

A test or an element instance sets a parameter that the part marks with
`adjustable = false`. Such parameters describe the part itself (for example
the nominal voltage that its curves refer to) and cannot change per
instance.

## Wrong

```toml
[[parameters]]
name = "v_nominal"
adjustable = false
# ...
[[tests]]
params = { v_nominal = "24 V" }
```

## Correct

```toml
[[tests]]
params = { }   # leave v_nominal alone, or make it adjustable
```
