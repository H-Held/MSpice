# E0060: unknown feature

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 8.

A feature is referenced but not declared with `[[features]]` (in this part,
or in the referenced part for `features = { ... }` of an instance).

## Wrong

```toml
[[parameters]]
name = "tc1"
feature = "thermals"
```

## Correct

```toml
[[features]]
name = "thermal"
description = "Temperature dependence"

[[parameters]]
name = "tc1"
feature = "thermal"
```

To see this text in a terminal: `mspice-libcheck explain E0060`.
