# E0061: feature dependency cycle

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 8.

The `requires` lists of features form a cycle, so enabling any of them would
have no defined end. Remove one requirement.

## Wrong

```toml
[[features]]
name = "esr"
requires = ["esl"]

[[features]]
name = "esl"
requires = ["esr"]
```

## Correct

```toml
[[features]]
name = "esr"

[[features]]
name = "esl"
requires = ["esr"]
```
