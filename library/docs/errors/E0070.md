# E0070: unknown element parameter

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 9.2.

A primitive element has a parameter that the element type does not know.
Element parameters use the short lower-case SPICE names (`r` for R, `c` for
C, `is`, `n`, `bv` for D, ...), not the names of your part parameters. Map
part parameters with expressions: `params = { r = "{resistance}" }`.

## Wrong

```toml
params = { resistance = "{resistance}" }
```

## Correct

```toml
params = { r = "{resistance}" }
```

To see this text in a terminal: `mspice-libcheck explain E0070`.
