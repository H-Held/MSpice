# E0071: missing element parameter

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 9.2.

A primitive element lacks a parameter without which it has no meaning: `r`
for R, `c` for C, `l` for L, `gain` for E, `gm` for G.

## Wrong

```toml
[model]
kind = "primitive"
element = "R"
nodes = ["p", "n"]
params = { tc1 = 0.001 }
```

## Correct

```toml
[model]
kind = "primitive"
element = "R"
nodes = ["p", "n"]
params = { r = "{resistance}", tc1 = 0.001 }
```

To see this text in a terminal: `mspice-libcheck explain E0071`.
