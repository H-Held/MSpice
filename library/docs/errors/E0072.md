# E0072: conflicting or missing alternative keys

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 9.3, 11, 14.

Of two or more alternative keys, exactly one must be given: an element has
`type` or `part`; a tolerance has `relative` or `absolute`; a transition needs
at least one trigger (`on`, `after`, `when`); a test expectation has
`value`, `min`/`max` or `file`.

## Wrong

```toml
[[model.elements]]
name = "R1"
type = "R"
part = "generic_resistor"
```

## Correct

```toml
[[model.elements]]
name = "R1"
part = "generic_resistor"
```
