# E0073: unknown part

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 9.3.

An element refers to a part id that is not loaded. When you check a single
file, other parts of the library are not loaded; check the library directory
or its `library.toml` instead. Otherwise the id is misspelt or the part
lives in a library that is not a dependency.

## Wrong

```toml
part = "generic_resistr"
```

## Correct

```toml
part = "generic_resistor"
```

To see this text in a terminal: `mspice-libcheck explain E0073`.
