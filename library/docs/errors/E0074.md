# E0074: part contains itself

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 9.3.

A part uses itself, directly or through other parts. Expanding it would
never end. The message shows the chain of parts.

## Wrong

```toml
# in generic_divider.toml
[[model.elements]]
name = "X1"
part = "generic_divider"
```

## Correct

```toml
# in generic_divider.toml
[[model.elements]]
name = "X1"
part = "generic_resistor"
```

To see this text in a terminal: `mspice-libcheck explain E0074`.
