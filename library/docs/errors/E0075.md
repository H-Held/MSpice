# E0075: unknown instance parameter

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 9.3, 14.

An instance (a test or an element with `part`) sets a parameter that the part
does not have. The hint names the closest parameter.

## Wrong

```toml
[[tests]]
params = { resistence = "2 kOhm" }
```

## Correct

```toml
[[tests]]
params = { resistance = "2 kOhm" }
```

To see this text in a terminal: `mspice-libcheck explain E0075`.
