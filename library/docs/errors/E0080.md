# E0080: expression syntax error

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 15.1.

An expression cannot be parsed. The column points at the problem. Typical
causes: a missing operand or parenthesis, a single `=` instead of `==`, unit
letters after a number (`1kOhm`; write `1k`), braces inside an expression,
or an `on` trigger that is not `rising(x)` / `falling(x)`.

## Wrong

```toml
params = { r = "{resistance * }" }
```

## Correct

```toml
params = { r = "{resistance * 2}" }
```

To see this text in a terminal: `mspice-libcheck explain E0080`.
