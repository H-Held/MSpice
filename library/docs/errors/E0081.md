# E0081: unknown name in expression

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 15.2.

An expression uses a name that is not defined: not a parameter, signal,
variable, input or built-in name. Also reported when an action assigns to
something that is not a state machine variable, or `rising()`/`falling()`
names something that is not an input.

## Wrong

```toml
params = { r = "{resistence}" }
```

## Correct

```toml
params = { r = "{resistance}" }
```

To see this text in a terminal: `mspice-libcheck explain E0081`.
