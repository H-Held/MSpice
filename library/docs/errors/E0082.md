# E0082: unknown function or wrong argument count

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 15.3.

A function is unknown, is called with the wrong number of arguments, or is
used where it is not allowed (`rising()` and `falling()` only in `on`;
`in_state()` only with a state machine). Curves are called with one
argument.

## Wrong

```toml
params = { r = "{sqr(resistance)}" }
```

## Correct

```toml
params = { r = "{sqrt(resistance)}" }
```

To see this text in a terminal: `mspice-libcheck explain E0082`.
