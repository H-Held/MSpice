# E0090: data file not found

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 13.1.

A data file named in `file` does not exist. Paths are relative to the part
file. The hint shows where the file was expected.

## Wrong

```toml
[[curves]]
file = "data/fan.csv"   # file is in data/fans/fan.csv
```

## Correct

```toml
[[curves]]
file = "data/fans/fan.csv"
```

To see this text in a terminal: `mspice-libcheck explain E0090`.
