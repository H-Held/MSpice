# E0091: malformed CSV file

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 13.3.

A CSV data file does not follow the format: comment lines start with `#`,
then a line of column names, a line of units, and at least two data rows of
plain numbers separated by `,`. No quotes, no `;`, no prefixes or units in
data cells.

## Wrong

```toml
voltage,current
V,A
0,0
1,1 mA
```

## Correct

```toml
voltage,current
V,A
0,0
1,0.001
```

To see this text in a terminal: `mspice-libcheck explain E0091`.
