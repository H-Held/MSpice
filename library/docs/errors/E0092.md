# E0092: x axis not strictly increasing

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 13.3, 14.

The x column of a curve (the first column, and any column used as `x`) must
be strictly increasing; the same holds for the time points of a `pwl`
stimulus. Sort the rows and remove duplicate x values.

## Wrong

```toml
voltage,current
V,A
0,0
2,0.002
1,0.001
```

## Correct

```toml
voltage,current
V,A
0,0
1,0.001
2,0.002
```

To see this text in a terminal: `mspice-libcheck explain E0092`.
