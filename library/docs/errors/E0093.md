# E0093: CSV column not found

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 13.1.

A curve or test expectation names a column that the CSV file does not have.
The hint lists the columns found in the header line.

## Wrong

```toml
[[curves]]
x = "voltage"
y = "currnet"
```

## Correct

```toml
[[curves]]
x = "voltage"
y = "current"
```

To see this text in a terminal: `mspice-libcheck explain E0093`.
