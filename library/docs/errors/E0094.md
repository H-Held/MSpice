# E0094: unknown curve

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 10, 13.

A load branch with `mode = "curve"` names a curve that is not declared with
`[[curves]]`.

## Wrong

```toml
[[model.branches]]
mode = "curve"
curve = "i_v"
```

## Correct

```toml
[[curves]]
name = "iv"
# ...
[[model.branches]]
mode = "curve"
curve = "iv"
```

To see this text in a terminal: `mspice-libcheck explain E0094`.
