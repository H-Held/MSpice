# E0095: data file path not allowed

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 13.1.

Data file paths must be relative, use `/`, and stay inside the directory of
the part file (no `..`, no absolute paths). This keeps every part
self-contained, so that libraries can be merged and moved.

## Wrong

```toml
file = "../shared/curve.csv"
```

## Correct

```toml
file = "data/curve.csv"
```

To see this text in a terminal: `mspice-libcheck explain E0095`.
