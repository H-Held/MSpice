# E0100: unknown state

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 11.

A state machine refers to a state that is not declared: in `initial`, in
`from`/`to` of a transition, or in `in_state()`. `from = "*"` means any
state; `to = "*"` is not allowed.

## Wrong

```toml
[[model.state_machine.transitions]]
from = "idle"
to = "bsuy"
```

## Correct

```toml
[[model.state_machine.transitions]]
from = "idle"
to = "busy"
```

To see this text in a terminal: `mspice-libcheck explain E0100`.
