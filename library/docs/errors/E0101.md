# E0101: unreachable state

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 11.

A state cannot be reached from the initial state through any transition. It
is dead code, or a transition into it is missing.

## Wrong

```toml
[[model.state_machine.states]]
name = "orphan"
# no transition has to = "orphan"
```

## Correct

```toml
[[model.state_machine.transitions]]
from = "idle"
to = "orphan"
when = "V(en) > 1"
```

To see this text in a terminal: `mspice-libcheck explain E0101`.
