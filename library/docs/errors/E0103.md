# E0103: unknown branch in state values

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 10, 11.

The `values` table of a state sets a branch that does not exist, or a branch
whose mode is not `state_machine` (such branches ignore state values).

## Wrong

```toml
values = { suply = "2 mA" }
```

## Correct

```toml
values = { supply = "2 mA" }
```

To see this text in a terminal: `mspice-libcheck explain E0103`.
