# E0111: expectation without tolerance

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 14.

An expectation with `value` or `file` has neither `abs_tol` nor `rel_tol`.
Simulation results are never exact; state how close they must be.

## Wrong

```toml
[[tests.expect]]
probe = "I(p)"
value = "1 mA"
```

## Correct

```toml
[[tests.expect]]
probe = "I(p)"
value = "1 mA"
rel_tol = 0.001
```
