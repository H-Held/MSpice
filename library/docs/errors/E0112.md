# E0112: expectation outside the analysis range

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 14.

The `at` point of an expectation lies outside the analysis: beyond `stop` of
a transient analysis, outside `from`..`to` of a DC sweep, or `at` is used with
an operating-point analysis, which has only one result.

## Wrong

```toml
analysis = "tran"
stop = "1 ms"
# ...
at = "2 ms"
```

## Correct

```toml
analysis = "tran"
stop = "3 ms"
# ...
at = "2 ms"
```
