# E0113: unknown stimulus

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 14.

The `sweep` of a DC test names a stimulus that the test does not define.

## Wrong

```toml
sweep = { stimulus = "v2", from = 0, to = 5, step = 0.1 }
[[tests.stimulus]]
name = "v1"
```

## Correct

```toml
sweep = { stimulus = "v1", from = 0, to = 5, step = 0.1 }
[[tests.stimulus]]
name = "v1"
```

To see this text in a terminal: `mspice-libcheck explain E0113`.
