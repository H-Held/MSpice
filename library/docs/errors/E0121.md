# E0121: dependency not found

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 2.

A dependency cannot be found, or the manifest at `path` belongs to a library
with another name. `path` is relative to the manifest and names a directory
with a `library.toml` or the manifest itself.

## Wrong

```toml
[[dependencies]]
name = "acme-sensors"
path = "../acme_sensors"
```

## Correct

```toml
[[dependencies]]
name = "acme-sensors"
path = "../acme-sensors"
```

To see this text in a terminal: `mspice-libcheck explain E0121`.
