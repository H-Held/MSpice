# E0122: dependency version not satisfied

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 2.

The dependency was found, but its version does not satisfy the requirement in
`version`.

## Wrong

```toml
[[dependencies]]
name = "base"
version = ">=1.0.0"   # base is 0.1.0
```

## Correct

```toml
[[dependencies]]
name = "base"
version = ">=0.1.0, <0.2.0"
```

To see this text in a terminal: `mspice-libcheck explain E0122`.
