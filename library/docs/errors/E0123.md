# E0123: merge conflict

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 3.

Two libraries define the same part id with different content and neither
says which one wins. Add an `[[overrides]]` entry to the later (dependent)
library, rename one part, or remove one copy. For a one-off merge,
`mspice-libcheck merge --on-conflict=first|last` decides explicitly.

## Wrong

```toml
# app/library.toml depends on base; both have generic_temp_sensor_1wire
```

## Correct

```toml
# app/library.toml
[[overrides]]
id = "generic_temp_sensor_1wire"
library = "base"
reason = "Measured conversion current"
```

To see this text in a terminal: `mspice-libcheck explain E0123`.
