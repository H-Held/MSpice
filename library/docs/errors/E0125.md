# E0125: invalid override

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 3.

An `[[overrides]]` entry names a library that is not a dependency, or an id
that the named library does not define. Such an entry would hide a typo, so
it is an error.

## Wrong

```toml
[[overrides]]
id = "generic_temp_sensr"
library = "base"
```

## Correct

```toml
[[overrides]]
id = "generic_temp_sensor_1wire"
library = "base"
```

To see this text in a terminal: `mspice-libcheck explain E0125`.
