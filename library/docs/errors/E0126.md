# E0126: dependency cycle

Severity: error. Specification: [SPEC.md](../../SPEC.md) section 2.

Libraries depend on each other in a circle. Move the shared parts into a
third library that both depend on.

## Wrong

```toml
# a/library.toml depends on b, b/library.toml depends on a
```

## Correct

```toml
# a and b both depend on common; common depends on nothing
```

To see this text in a terminal: `mspice-libcheck explain E0126`.
