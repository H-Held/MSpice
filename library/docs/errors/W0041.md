# W0041: pin not used by the model

Severity: warning. Specification: [SPEC.md](../../SPEC.md) section 6.

A pin is declared but the model never connects it, so it would float in
every circuit. Either the model is incomplete or the pin does not exist on
the device. This warning is only given when the model itself has no errors.

## Wrong

```toml
[[pins]]
name = "sense"
role = "analog"
# no element, output, branch or V()/I() uses "sense"
```

## Correct

```toml
[[pins]]
name = "sense"
role = "analog"

[[model.elements]]
name = "Rsense"
type = "R"
nodes = ["sense", "gnd"]
params = { r = "1 MOhm" }
```

To see this text in a terminal: `mspice-libcheck explain W0041`.
