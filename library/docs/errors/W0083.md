# W0083: ambiguous SPICE suffix M

Severity: warning. Specification: [SPEC.md](../../SPEC.md) section 15.1.

In SPICE expressions, `M` and `m` both mean milli; mega is `meg`. A number
like `1M` is therefore 0.001, which is almost never what was meant. (In
quantity strings such as `"1 MOhm"` the SI rule applies and `M` is mega.)

## Wrong

```toml
params = { r = "{resistance + 1M}" }
```

## Correct

```toml
params = { r = "{resistance + 1meg}" }
```

To see this text in a terminal: `mspice-libcheck explain W0083`.
