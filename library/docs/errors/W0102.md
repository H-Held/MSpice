# W0102: state without way out

Severity: warning. Specification: [SPEC.md](../../SPEC.md) section 11.

A reachable state has no outgoing transition, so the machine would stop
there forever. If that is intended (an error or end state), mark it with
`final = true`.

## Wrong

```toml
[[model.state_machine.states]]
name = "stuck"
```

## Correct

```toml
[[model.state_machine.states]]
name = "stuck"
final = true
```
