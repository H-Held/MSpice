# W0110: part has no reference tests

Severity: warning. Specification: [SPEC.md](../../SPEC.md) section 14.

The part has no `[[tests]]` entry. Reference tests describe the expected
behaviour and will be simulated in CI (roadmap stages 2 and 5). Parts of
quality `datasheet` or `measured` must have tests (E0022).

## Wrong

```toml
# part file ends after [model]
```

## Correct

```toml
[[tests]]
name = "ohms_law"
analysis = "op"

[[tests.stimulus]]
name = "v1"
nodes = ["p", "n"]
source = "voltage"
waveform = "dc"
value = "1 V"

[[tests.expect]]
probe = "I(p)"
value = "1 mA"
rel_tol = 0.001
```

To see this text in a terminal: `mspice-libcheck explain W0110`.
