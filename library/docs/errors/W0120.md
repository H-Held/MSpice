# W0120: pattern matches no file

Severity: warning. Specification: [SPEC.md](../../SPEC.md) section 2.

A glob pattern in the `parts` list of a manifest matches no `.toml` file.
`*` does not cross directory boundaries; use `**` to include subdirectories.

## Wrong

```toml
parts = ["parts/*.toml"]   # files are in parts/loads/
```

## Correct

```toml
parts = ["parts/**/*.toml"]
```

To see this text in a terminal: `mspice-libcheck explain W0120`.
