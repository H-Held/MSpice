# W0124: identical part defined twice

Severity: warning. Specification: [SPEC.md](../../SPEC.md) section 3.

Two libraries contain byte-identical copies of a part (apart from line
endings). The part is used once. Remove one copy or declare an override to
make ownership explicit.

## Wrong

```toml
# base/parts/generic_led.toml and app/parts/generic_led.toml are identical
```

## Correct

```toml
# keep the part in one library only
```

To see this text in a terminal: `mspice-libcheck explain W0124`.
